# Chair Renew Venture 3D Studio

Chair Renew is a repair-first office-chair restoration concept. This Mission 2 studio turns the concept into an editable browser-based 3D prototype with separate chair components for upholstery, armrest, and structural design changes.

## Student guide

1. Open the studio and drag inside the viewport to orbit the chair. Scroll to zoom.
2. Select a component from the Scene objects list or click a part in the model.
3. Choose a color swatch or use the color picker to change the upholstery or hardware.
4. Adjust Component width to explore a meaningful design change.
5. Click Save project to keep the current design in this browser.
6. Click Confirm model to prepare the Mission 3 handoff package.

The supplied restoration showcase is preserved at `public/references/chair-restoration-showcase.png` as the concept reference. The 3D model is an editable procedural approximation; it is not an automatic reconstruction of the 2D image.

## Local development

```sh
npm install
npm run dev
npm run build
```

The Vite base path is configured for a repository named `venture-3d-studio`.

## Mission 2 limitation

The local source and production build are complete. GitHub publication and final browser QA still require a writable GitHub checkout or a connected GitHub push. Do not describe the site as published until the Pages URL has been opened and verified.
